### Added

- Godot 4.x project scaffolding (`project.godot`, editor config, `.gitignore`).
- `addons/godot_ai` AI-assisted development plugin integration.
- Project README describing Phylaworld and its connected universe.
- Community governance files: `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`,
  `LICENSE` (AGPL-3.0), `SECURITY.md`.
- GitHub issue and pull request templates.
- Repository label set (`.github/labels.yml`) with automatic label sync.
- Automated SemVer release pipeline:
  `version.json`, `CHANGELOG.md` and the `Release (version bump & changelog)`
  workflow.
